# Проверка GREEN-API

Статическая страница для проверки четырёх методов WhatsApp API GREEN-API. Слева находятся параметры подключения и действия, справа отображается ответ API в поле только для чтения.

[Открыть страницу](https://auyenn.github.io/green-api-support-demo/)

## Как проверить

1. В [кабинете GREEN-API](https://console.green-api.com/) создайте инстанс WhatsApp и подключите свой номер через QR-код. Для тестирования подойдёт тариф «Разработчик».
2. На странице укажите `idInstance` и `ApiTokenInstance`. Если в кабинете для вашего инстанса указан отдельный `apiUrl`, раскройте «Другой адрес API» и вставьте этот адрес.
3. Нажмите `getSettings` и `getStateInstance`. Для отправки сообщений состояние должно быть `authorized`.
4. Для `sendMessage` укажите номер с кодом страны и текст. Для `sendFileByUrl` укажите номер и прямую ссылку на файл. Имя определяется по ссылке, а для адресов без расширения его можно ввести вручную. Для теста используйте номер, с которым вы вправе проводить проверку.

Каждый запрос выполняется после нажатия кнопки. HTTP-статус и тело ответа отображаются на странице. `idMessage` означает, что GREEN-API принял сообщение к отправке. Доставку можно проверить в WhatsApp.

## Демо и локальный запуск

Переключатель «Демо без отправки» позволяет посмотреть примеры ответов всех четырёх методов без учётных данных и сетевых запросов.

Для локального запуска из корня репозитория выполните `python -m http.server 8080 --bind 127.0.0.1` и откройте `http://127.0.0.1:8080/`.

В рабочем режиме запросы идут из браузера напрямую в GREEN-API. Страница не сохраняет токен в хранилище браузера и скрывает его при отображении ответа. В репозитории нет учётных данных.

[Документация GREEN-API по формату запросов](https://green-api.com/docs/request-format/)
